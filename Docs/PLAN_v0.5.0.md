## 设计背景

### 老政（NPC）
- **身份**：零号区南边饮品铺的老板。店铺被风暴怪物砸毁，投奔零号区地堡。
- **性格**：懒散，喜欢喝咖啡。与杰夫（原游戏NPC）和老吴关系不错。
- **暗面**：私下研究武器和装备转卖熟人（与老吴关系好的原因之一）。军火交易作为联动预留，本模组仅任务彩蛋暗示。
- **紫色爱好**：喜欢葡萄制品（葡萄汽水、葡萄酒等），任务线中会有线索。
- **解锁方式**：**不是初始NPC**。玩家需先完成杰夫的任务 → 获得饮品制作台图纸 → 建造饮品制作台 → 老政出现。

### 饮品制作台
- **模型**：自定义 3D 模型，AssetBundle 加载。
- **功能**：
  1. 放置后**生成 NPC 老政**（触发器）。
  2. 交互面板：制作饮品 + 咖啡厅简餐（美食类食物）。
  3. 配方需自行录入（标签 `DrinkStation`）。
- **与游戏原版工作台的分工**：
  - 原版工作台：生存干粮类食品 + 食材基本处理 + 净水合成
  - 饮品制作台：饮品 + 美食类食物
- **解锁**：杰夫任务奖励图纸。

### 净水器
- **模型**：自定义 3D 模型，AssetBundle 加载。
- **设计参考**：类似原版游戏比特币挖矿机。
- **功能**：自动产出纯净水(30010)。
- **反向合成**：瓶装水（原版物品）+ 净水片 → 纯净水（在原版工作台中）。
- **加速**：升级模块（非消耗品，永久安装）+ PerkTree 升级。
- **剧情**：任务线中说明——当前水域水质达不到老政要求，需要净水器。

### 任务线
- 分为**前置阶段**（杰夫发布，引导建造饮品制作台）和**核心阶段**（老政发布，配方收集+处理麻烦）。
- 配方全部 `unlockByDefault = false`，通过任务逐步解锁。
- 任务类型：提交物品、制作物品、击杀目标（"处理麻烦"）。

### 技能树
- 独立 PerkTree，专门设计的图标。
- 饮品增强 + 净水效率 两条分支。

### 2B. 净水器（参考原版比特币挖矿机）

| 属性 | 值 |
|---|---|
| Identifier | `dockov_drinks:building_water_purifier` |
| 占地 | 1×2 |
| 模型 | AssetBundle `water_purifier` → `WaterPurifier_Prefab` |
| 功能 | 自动产出纯净水(30010) |
| 解锁条件 | 完成老政核心任务2「净水问题」 |

**产出机制**（参考比特币挖矿机设计）:

| 参数 | 默认值 | 说明 |
|---|---|---|
| 基础产出间隔 | 6 游戏小时 | |
| 单次产出量 | 1 瓶 | |
| 最大存量 | 5 瓶 | 满仓停止，需手动收集 |
| 升级槽 #1（滤水膜） | — | 永久安装，间隔 ×0.5 |
| 升级槽 #2（储水罐） | — | 永久安装，单次产出 +1 |
| Perk：净水基础 | — | 间隔 ×0.85 |
| Perk：高效过滤 | — | 间隔 ×0.75 |
| Perk：大容量储水 | — | 最大存量 +5 |

**叠加公式**: `实际间隔 = 6h × 0.5(滤水膜) × 0.85(净水基础) × 0.75(高效过滤) ≈ 1.9h`  
**满升级产出**: 每 ~1.9h 产出 2 瓶，最大存量 10 瓶

**升级模块机制**（非消耗品）:
- 放入升级槽后永久生效，可取出
- 每个模块唯一绑定一个净水器
